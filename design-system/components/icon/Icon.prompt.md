One-sentence: renders a single line glyph that inherits text colour — use for every icon rather than inlining SVG.

```jsx
<Icon name="arrow-right" size={16} />
<Icon name="building-2" size={24} label="Construction" />
```

House glyph set: arrow-right, arrow-up-right, plus, minus, x, check, chevron-down, chevron-right, search, menu, mail, phone, map-pin, ruler, building-2, sofa, hard-hat, globe, download, calendar, user, external-link.
