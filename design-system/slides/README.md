# Sample slides

Seven slide types derived from `uploads/Apresentação-Barbeitos.pdf` and the
brand manual. Each file is a fixed 1280×720 frame that links the root
`styles.css`, so every value comes from the token layer.

| File | Type | Ground |
| --- | --- | --- |
| `01-cover.html` | Cover | Midnight Navy |
| `02-section-divider.html` | Numbered divider | Onyx Black |
| `03-statement.html` | Single manifesto statement | Paper |
| `04-three-columns.html` | The three divisions | Paper |
| `05-image-split.html` | Half-bleed image + data list | Paper |
| `06-palette.html` | Sistema de cores band | Paper + brand swatches |
| `07-closing.html` | Script signature closing | Midnight Navy |

Rules the deck follows: two grounds only per deck (paper + one dark);
the script face appears exactly once per deck, on the cover or the closing;
page numbers and the wordmark sit on the same baseline in the footer;
photography is always full-bleed to at least one slide edge.
